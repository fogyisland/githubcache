# M13 — Full-site i18n (zh + en) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship complete zh + en bilingual layer across every user-facing page. No hardcoded English strings remain in any UI component.

**Architecture:** next-intl foundation → message dictionaries (`messages/{zh,en}.json`) → switch out every UI string to `t('key')` calls → cookie + DB locale persistence → language switcher in chrome.

**Tech Stack:** next-intl, Next.js 14 App Router server/client components, Prisma, MySQL, Vitest + renderToStaticMarkup, existing design-system tokens.

**Spec:** `docs/superpowers/specs/2026-08-28-m13-i18n.md` (M13 design, approved)

## Global Constraints

These apply to every task:

- **TypeScript strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`** — use spread idiom `...(condition ? { field: value } : {})` for optional properties.
- **next-intl pattern**: server components `import { getTranslations } from 'next-intl/server'` then `const t = await getTranslations('namespace')`. Client components `import { useTranslations } from 'next-intl'` then `const t = useTranslations('namespace')`.
- **Locale config**: `LOCALES = ['zh', 'en']`, `defaultLocale = 'zh'`. Detection order: cookie `ghc_lang` > DB `users.lang` > `Accept-Language` > `zh`.
- **Cookie**: `ghc_lang`, 1 year MaxAge, Path=/, SameSite=Lax. Mirror `ghc_theme` cookie pattern.
- **No URL prefix** — locale does not affect URL paths.
- **MySQL local time zone quirk**: use `UTC_TIMESTAMP(6)` not `NOW()` in raw SQL.
- **No new dependencies beyond next-intl.**
- **No Docker for deploy** (M8 reverted).
- **Auth boundary interfaces**: never call `cookies()` from `next/headers` in tests — use `cookiesFromRequest(req)` (M7 helper).
- **Three-theme compatibility is automatic** if you read from `--color-*`, `--font-*` CSS variables — never hard-code hex colors.
- **Server components by default**; only interactive bits need `'use client'`.

   ```ts
   import { LOCALES, defaultLocale, type Locale } from '@/i18n/config';
   export { LOCALES, defaultLocale };
   export type { Locale };
   export function isLocale(s: string | undefined | null): s is Locale {
     return typeof s === 'string' && (LOCALES as readonly string[]).includes(s);
   }
   export function resolveLocale(opts: {
     cookieValue?: string | null;
     dbValue?: string | null;
       acceptLanguage?: string | null;
   }): Locale {
     if (isLocale(opts.cookieValue)) return opts.cookieValue;
     if (isLocale(opts.dbValue)) return opts.dbValue;
     const al = opts.acceptLanguage ?? '';
     if (al.toLowerCase().startsWith('en')) return 'en';
     return defaultLocale;
   }
   ```

   export default getRequestConfig(async ({ requestLocale }) => {
     let locale = await requestLocale;
     if (!isLocale(locale)) locale = defaultLocale;
     return {
       locale,
       messages: (await import(`../../messages/${locale}.json`)).default,
